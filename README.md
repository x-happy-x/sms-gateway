# SMS Gateway для MikroTik и Entware

Установлен на Netcraze: http://192.168.1.1:8099
Веб-интерфейс открывается без авторизации.

- Входящие: чтение исходных PDU через RouterOS API и AT+CMGL; UCS2/кириллица, GSM7, объединение частей длинных SMS.
- Архив: `/opt/sms-gateway/archive.sqlite`, опрос каждые 30 секунд. Исходные PDU тоже сохраняются.
- SIM: после записи и фиксации SMS в архиве сервис сразу проверяет содержимое ячейки и удаляет сообщение с SIM. Сообщения с ошибкой декодирования остаются на SIM. Опрос каждые 30 секунд после завершения предыдущего цикла; операции SMS/USSD могут задержать очередной опрос.
- Отправка: штатный `/tool/sms/send`, GSM7 до 160 единиц. Кириллица исходящих напрямую не поддерживается RouterOS 7.20.5. Кнопка «В транслит» преобразует текст до отправки, результат виден пользователю. Отправка требует подтверждения в интерфейсе.
- USSD: баланс T2 `*105#`, номер `*201#`, произвольные запросы и ответы. Ожидание до 120 секунд. EG18 может прерывать LTE при USSD; автоматических USSD-запросов нет.
- История операций, запрет параллельных действий, idempotency id для API; автоматических повторов отправки нет. Успех отправки означает подтверждение RouterOS, а не доставку получателю.

## Управление на Netcraze

```sh
/opt/etc/init.d/S99sms-gateway status
/opt/etc/init.d/S99sms-gateway restart
/opt/etc/init.d/S99sms-gateway stop
```

Автозапуск через Entware init.d. Лог: `/opt/var/log/sms-gateway.log`.
Python стандартной библиотеки; дополнительные пакеты не устанавливались на Netcraze.
Сервис слушает только 192.168.1.1:8099. Без авторизации; CSRF token защищает изменяющие запросы; предназначен для доверенной LAN, TLS не настроен.

На MikroTik добавлены пользователь и группа `smsgw` (read, write, test, api), вход пользователя ограничен адресом Netcraze 192.168.188.254. Для USSD добавлены memory logging action `smsgw` на 100 записей и правило с prefix=smsgw и regex `CUSD:|CMGS:|CMS ERROR`. Доступ администратора не используется сервисом.

## Проверка

9 существующих SMS декодированы и сохранены. Получены ответы T2 с номером и балансом (400.00 руб. на момент проверки). Проверены доступ без пароля, 403 без CSRF, 400 для неверного номера, сохранность архива после перезапуска сервиса, unit tests кодеков и валидатора.
Фактическая отправка платного тестового SMS не выполнялась.

Прямой AT+CMGS через RouterOS at-chat НЕ используется: при проверке обнаружен тайм-аут/зависание модема, потребовавшее перезапуска MikroTik пользователем. Экспериментальный port remote-access удалён.

## Резервная копия

Для согласованной копии SQLite используйте sqlite3 Connection.backup() или остановите сервис и копируйте каталог целиком (включая -wal/-shm при наличии). Конфигурация содержит секреты: сохраняйте права 600 и не публикуйте её.
