Пересылка SMS

Новые входящие уходят на другой номер отдельными SMS. RouterOS отправляет только латиницу, поэтому текст транслитерируется, а длинные сообщения делятся на части. Неудачная пересылка не повторяется автоматически.

Последние пересылки

Лимит SMS в месяц

Считается каждое SMS, подтверждённое RouterOS: из интерфейса, API и каждая часть пересылки. При исчерпании отправка отклоняется, а новые сообщения не пересылаются и не копятся до обновления.

SIM-карта

SMS проверяются каждые 30 секунд. После сохранения в архив сообщения удаляются с SIM; сообщения с ошибкой декодирования остаются на SIM для проверки.

Занято ячеекКогда память заполнена, новые SMS не принимаются —
Освободить памятьУдаляет с SIM только уже сохранённые в архив сообщения

API

Доступ по токену в заголовке Authorization: Bearer <token>. Токен выпускается на роутере и показывается один раз:

/opt/bin/python3 /opt/sms-gateway/server.py token add my-service
/opt/etc/init.d/S99sms-gateway restart
GET /api/v1/messagesunread=1, sender, since, order=asc, limit, offset

POST /api/v1/messages/read{"ids":[1,2],"read":true}
POST /api/v1/send{"number":"+7…","text":"…","id":"необязательно"}
GET /api/v1/operations/{id}статус отправки
GET /api/v1/limitsлимит и остаток; сверх лимита send отвечает 429
