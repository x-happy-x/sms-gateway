Журнал

Отправка, пересылка, USSD и обслуживание SIM. Успешная отправка — подтверждение RouterOS, а не отчёт о доставке.

Настройки

Пересылка SMS

Новые входящие отправляются на указанный номер отдельными SMS. RouterOS отправляет только латиницу, поэтому текст транслитерируется, длинные сообщения делятся на части. Пересылаются только сообщения, пришедшие после включения; неудачные отправки не повторяются автоматически.

Последние пересылки

Лимит SMS в месяц

—отправлено в этом периоде

Считается каждое SMS, подтверждённое RouterOS: отправка из интерфейса и API, каждая часть пересылки. При исчерпании отправка отклоняется, а новые сообщения не пересылаются и не копятся до обновления лимита.

Память SIM

—ячеек занято

SMS проверяются каждые 30 секунд. После сохранения в архив сообщения удаляются с SIM; сообщения с ошибкой декодирования остаются на SIM для проверки.

API

Доступ по токену: Authorization: Bearer <token>. Токен выпускается на роутере и показывается один раз:

/opt/bin/python3 /opt/sms-gateway/server.py token add my-service
/opt/etc/init.d/S99sms-gateway restart
